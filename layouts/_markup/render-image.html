{{/* Image render hook — HeimaEden ------------------------------------------------------------------ Turns plain Markdown `![alt](/images/foo.png)` into a performance- correct tag, without changing any article syntax. What it fixes (see CLAUDE.md §3.3): - LCP : downscales to MAXW and re-encodes as WebP at build time - CLS : always emits width/height so the browser reserves space - Above/below fold: first image on a page loads eager+high priority, every later image is lazy Resolution order for the destination path: 1. external URL (http/https) -> passthrough, no processing 2. assets/ -> processed (resize + webp) 3. anything else (e.g. static/) -> passthrough + lazy only Note: static/images/og-default.png is intentionally NOT processed. Social scrapers handle WebP unreliably and OG images need a stable, non-fingerprinted URL. */}} {{- $maxW := 1440 -}} {{- $quality := "webp q85" -}} {{- $dest := .Destination | safeURL -}} {{- $alt := .Text | plainify -}} {{- $title := .Title -}} {{- $isFirst := eq .Ordinal 0 -}} {{- /* 1. External URL: never touch */ -}} {{- if or (hasPrefix $dest "http://") (hasPrefix $dest "https://") (hasPrefix $dest "//") -}} {{- else -}} {{- /* Normalise "/images/foo.png" -> "images/foo.png" for assets lookup */ -}} {{- $lookup := strings.TrimPrefix "/" $dest -}} {{- $res := resources.Get $lookup -}} {{- if $res -}} {{- /* 2. Found in assets/: resize (only if oversized) then encode WebP */ -}} {{- $img := $res -}} {{- if gt $img.Width $maxW -}} {{- $img = $img.Resize (printf "%dx %s" $maxW $quality) -}} {{- else -}} {{- $img = $img.Process $quality -}} {{- end -}} {{- else -}} {{- /* 3. Not in assets/ (static/ file or missing): passthrough */ -}} {{- warnf "render-image: %q not found under assets/ — served unprocessed, no width/height (page: %s)" $dest .Page.Path -}} {{- end -}} {{- end -}}
